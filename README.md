# 🫧 Bubble Blast

A fun, polished **bubble shooter** that runs in any browser (phone or PC). 10 levels, limited shots, combos, sound effects and saved progress. No libraries, no build step: just HTML + CSS + JavaScript.

## ✨ Features

- 🎯 10 levels with growing difficulty (more colors, more rows, ceiling drops)
- 🔢 Separate **Shots Left** and **Fired** counters
- 🌟 3-star rating per level, progress and best scores saved in the browser
- 🔗 Combo scoring, falling bubbles, particle effects
- 🧭 Aim guide with wall-bounce preview and landing ghost
- 🔄 Swap the current and next bubble
- 🔊 Sound effects (mute with `M`)
- 📱 Works with touch and mouse

## 🎮 Controls

| Action | Mouse / Touch | Keyboard |
|---|---|---|
| Aim | Move mouse / drag finger | ← → |
| Shoot | Click / release finger | Enter or ↑ |
| Swap bubble | Click the NEXT bubble | Space |
| Restart level | ↻ button | R |
| Mute | 🔊 button | M |

## ▶️ Run locally

Just open `index.html` in a browser. That's it.

## 🌍 Publish on GitHub Pages (free)

1. Create a new **public** repository on GitHub.
2. Upload `index.html`, `style.css`, `game.js`, `README.md`, `LICENSE`.
3. Go to **Settings → Pages**.
4. Under *Build and deployment*, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After a minute your game is live at `https://<your-username>.github.io/<repo-name>/`.
